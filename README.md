# Автотесты для сервиса «Яндекс.Самокат»

Проект содержит автоматизированные UI-тесты для сервиса «Яндекс.Самокат» (https://qa-scooter.praktikum-services.ru/). 
В проекте применён паттерн Page Object Model и подключён Allure-отчёт для наглядной визуализации результатов тестирования.

## Структура проекта

```
├── tests/                      # Директория с тестами
│ ├── init.py                   # Пустой файл для создания Python-пакета
│ ├── test_main_page.py         # Тесты главной страницы (FAQ)
│ ├── test_order_page.py        # Тесты оформления заказа
│ └── test_clicks.py            # Тесты переходов по логотипам
│
├── pages/                      # Page Object классы
│ ├── init.py                   # Пустой файл для создания Python-пакета
│ ├── base_page.py              # Базовый класс страницы
│ ├── main_page.py              # Главная страница
│ └── order_page.py             # Страница заказа
│
├── locators/                   # Локаторы элементов
│ ├── init.py                   # Пустой файл для создания Python-пакета
│ ├── general_locators.py       # Общие локаторы
│ ├── main_page_locators.py     # Локаторы главной страницы
│ └── order_page_locators.py    # Локаторы страницы заказа
│
├── allure-report/              # Сгенерированный Allure-отчёт
│
├── data.py                     # Тестовые данные
├── urls.py                     # URL-адреса
├── conftest.py                 # Фикстуры pytest
├── requirements.txt            # Зависимости проекта
├── .gitignore                  # Список игнорируемых файлов
└── README.md                   # Документация проекта
```

## Покрываемые сценарии

### 1. FAQ - Вопросы о важном
- Проверка выпадающего списка с ответами на 8 вопросов
- Каждый вопрос тестируется отдельно с проверкой соответствующего текста ответа
- Автоматический скролл к блоку вопросов для стабильности тестов

### 2. Оформление заказа самоката
- Позитивный сценарий заказа через верхнюю кнопку "Заказать"
- Позитивный сценарий заказа через нижнюю кнопку "Заказать"  
- Заполнение всех полей формы: личные данные, адрес, станция метро, данные аренды
- Проверка успешного создания заказа через модальное окно подтверждения

### 3. Переходы по логотипам
- Клик по логотипу Самоката - переход на главную страницу
- Клик по логотипу Яндекса - открытие Дзена в новой вкладке
- Проверка корректности переходов по наличию ключевых элементов
